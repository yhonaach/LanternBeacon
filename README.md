# LanternBeacon

Turns open-source data validation tools into a user-friendly interface who need to verify data consistency across various systems.

LanternBeacon is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/LanternBeacon.git`
2. `cd LanternBeacon`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure LanternBeacon, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
